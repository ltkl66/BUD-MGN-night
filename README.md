# 8.26 黑金之夜 · SPR 数据收集

一个纯网页版的数据收集小项目：SPR 在手机上打开问卷链接填写数据，自动存入 Supabase 数据库；打开看板链接实时查看所有记录和汇总。

## 文件清单

| 文件 | 作用 | 要不要上传到 GitHub |
|---|---|---|
| `survey.html` | 问卷页（SPR 填写用） | ✅ 要 |
| `dashboard.html` | 看板页（查看数据用） | ✅ 要 |
| `index.html` | 入口页（两个按钮跳转） | ✅ 要（可选） |
| `supabase_setup.sql` | 第一次建库用的脚本 | ❌ 不用上传，只在 Supabase 后台跑 |

| `supabase_update_m3.sql` | ❌ 已过时，不用再跑 | ❌ |
| `README.md` | 本说明 | 可传可不传 |

> 网页已把 Supabase 代码库内置，不依赖任何外部网络资源，国内网络也能正常打开。

## 问卷填什么（v2 版）

问卷分 4 个板块，SPR 一共只需填写 **12 个数字**，其余自动计算：

| 板块 | 填写项 | 自动计算项 |
|---|---|---|
| 1 门店信息 | 门店（下拉）、M3、活动日期、SPR姓名 | - |
| 2 赠品黑金255罐 | 机制1 / 机制2 / 机制3 / 机制4 | 赠品黑金255罐数量 = 机制1+2+3+4 |
| 3 ABI（百威品牌）销量 | 百威家族（不含黑金：经典/金尊/纯生）、黑金（1L罐/500瓶/330罐/250瓶）、其他（科罗娜、哈啤等） | 黑金合计 = 4个SKU之和；当晚ABI总销量 = 百威家族+黑金+其他 |
| 4 竞品销量 | 重点竞品 / 其他竞品 | 竞品总销量 = 两者和；啤酒总销量 = ABI + 竞品 |

## 第一步：Supabase 建库/更新（只需做一次，约 2 分钟）

**情况 A：已经建过库了**（之前跑过任何版本 SQL）
1. 打开 https://supabase.com 登录 → 进入项目 → 左侧 **SQL Editor** → 新建查询
2. 打开本文件夹里的 `supabase_update_v3.sql`，全部复制粘贴，点 **Run**
3. 出现「数据库更新成功！」即完成（这个脚本是最终版，包含之前的 M3 更新）

**情况 B：第一次建库**
1. 同上操作，粘贴运行 `supabase_setup.sql` 的内容
2. 出现「数据库创建成功！」即完成

---

## 第二步：上传/更新网页到 GitHub

**第一次上传：**
1. https://github.com → 右上角 **+** → **New repository** → 名字如 `blackgold-night`，选 **Public** → 创建
2. 在新页面点 **uploading an existing file**，把 `survey.html`、`dashboard.html`、`index.html` 三个文件拖进去 → **Commit changes**

**更新（网页改过之后，重要！）：**
1. 仓库里点开旧文件 → 右上角 **...** 或垃圾桶图标 → **Delete file** → Commit changes（先删旧文件）
2. 点 **Add file → Upload files** → 把新文件拖进去 → Commit changes（再传新文件）
3. 三个文件都按这个方式更新（survey.html、dashboard.html、index.html）
4. 打开页面按 **Ctrl+F5** 强制刷新（手机上用无痕窗口）

> 不要用「铅笔图标」编辑器粘贴大文件（200多KB容易出错），一定用「删旧传新」的方式。

---

## 第三步：开启 GitHub Pages（生成链接）

1. 仓库页面点 **Settings** → 左侧 **Pages**
2. **Branch** 选 `main`，文件夹选 `/ (root)` → **Save**
3. 等 1~2 分钟，顶部绿色提示框显示：`https://你的用户名.github.io/你的仓库名/`
4. 三个链接：
   - 入口页：`https://你的用户名.github.io/你的仓库名/`
   - 问卷页：`https://你的用户名.github.io/你的仓库名/survey.html`
   - 看板页：`https://你的用户名.github.io/你的仓库名/dashboard.html`

---

## 第四步：测试（一定要做）

1. 打开**问卷链接**：门店下拉应有 A/B/C/D/E
2. 选门店 A、填 M3、日期、姓名，机制1-4 各填几个数字 → 页面应实时显示「赠品黑金255罐」自动合计
3. 销量 8 项各填几个数字（含黑金4个SKU）→ 页面应实时显示 黑金/ABI/竞品/啤酒合计
4. 提交 → 再提交一次同店同日期 → 看板验证数字是两次总和
5. 打开**看板链接**：从上到下依次是 汇总合计 → 门店看板 → M3看板 → 明细记录；筛选门店/M3/日期后各卡片同步变化

---

## 修改门店列表（以后换成你的 100 家门店）

1. 记事本打开 `survey.html`，找到：
   ```js
   const STORE_LIST = ['A','B','C','D','E'];
   ```
2. 改成你的门店名单，用英文逗号隔开：
   ```js
   const STORE_LIST = ['杭州店','上海店','苏州店','南京店'];
   ```
3. 保存后按「更新网页」方式重新上传
4. 看板会自动显示数据库里已有的门店，无需改看板

> 也可以把 100 家店名发给我，我帮你批量替换好。

## 其他说明

- **M3**：目前由 SPR 在问卷里手填；以后你提供「门店 ↔ M3」对应表，可以改成选门店自动带出
- **数据修改/删除**：Supabase 后台左侧 **Table Editor** → `spr_records` 表 → 直接改或删行
- **密钥安全**：网页里用的是 `anon public` 公钥，安全；`service_role`（Secret）密钥**千万不要**放进网页或发给别人
- **提交失败**：先确认已运行最新版 SQL（`supabase_update_v3.sql`）；老数据里的旧字段不影响新填写
